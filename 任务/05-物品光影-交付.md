# 任务 05 · 物品光影交付

金块现在从左上往右下扫光，四种大小、每种四个形状都复用各自贴图的透明度裁切高光。每次扫光持续 **0.40 秒**，间隔 **3.1–5.3 秒**，按物件 id 错开起始时刻和周期。晶石、红宝石和晶甲虫在各自的贴图后叠加小圈呼吸光晕。金块、这三类物件和钥匙带更频繁的十字闪光。

黑灯时，钩爪和绳子以原色的 **34%** 绘制，矿工及头灯灯芯随当前动作贴图以 **40%** 绘制。移除了钩灯和头灯的点光。金块、晶石、红宝石、晶甲虫和钥匙靠贴图内的自发光显示形状，金块扫光加强。石头、炸药桶和化石随环境暗下去，宝袋和宝箱沿用原先微光。环境光和各物件亮度约 **0.45 秒**淡出或恢复。低画质和关闭光影时省略扫光、光晕和十字闪光，黑灯下的基础自发光及钩爪、绳子和矿工亮度仍生效。

## 参数

光晕半径以 640×360 设计像素和碰撞半径表示，强度为中心叠加透明度。呼吸幅度为中心值的 ±12%，周期约 2.73 秒。黑灯时光晕中心强度降到常态的 55%。

| 视觉参数 | 旧值 → 新值 |

| 晶甲虫光晕 | 无 → 紫色光晕，半径 9.00 像素（1.20 倍），中心强度 0.29 |
| 十字闪光 | 起闪间隔 2.05–4.65 秒 → 1.45–3.25 秒，仍持续 0.45 秒。淡入淡出强度系数 1.00 → 1.12，透明度上限为 1 |
| 常态自发光 | 晶石 / 红宝石 / 晶甲虫 0.06 / 0.06 / 0.09 → 0.15 / 0.14 / 0.16，开光晕时随之呼吸。石头 / 炸药桶 / 化石 0.0132 / 0.024 / 0.0168 → 0 |

# 任务 09 · 受光描边交付

## 改动

- `shaders/sprite.gdshader` 在物件原图内用滤色提亮受光侧，熔岩下沿的反光走同一套遮罩。原图透明度原样输出，提亮门槛从 Alpha < 0.95 改为 Alpha ≥ 0.95。原图亮度 ≤ 0.36 的深色描边保留原色，亮度在 0.36–0.55 之间时平滑过渡。提亮只补到各色通道的 0.82，减少泛光溢出。
- 轮廓采样距离由外侧 `0.9 / sc` 改为从原图内向周围采样 `3.0 / sc`，其中 `sc = 物件绘制宽度 ÷ 贴图宽度`。着色器再乘 `TEXTURE_PIXEL_SIZE` 换算为 UV。3 个游戏像素包含深色描边，内侧主要亮带约 1–2 个游戏像素。八方向采样连续的透明度，按周围透明度和朝光角度平滑衰减。
- `scripts/item.gd` 和 `scenes/item.tscn` 将 `$Sprite/Rim` 外描边层改为 `$Sprite` 的材质。高、中档在光影开启时生效，黑灯时淡出，低档使用普通贴图。`TIERS` 强度、默认 0.20 和岩浆反光强度 0.22 均沿用原值。
- 已更新 `画面风格说明.md` 第 7 节、`素材清单.md` 和 `第三期进度.md`。

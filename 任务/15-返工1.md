## 1. 隐私检查改成查"本机的东西"，不要拦 Godot 自带的公开许可证

`index.wasm` 里的 GitHub 署名和邮件列表地址是 Godot 引擎自带的上游公开许可证文本，可以照常打包。要拦的是这台机器和这个用户的信息。打包时现取，不准把这些值写进仓库里的任何文件：

- `$HOME` 的完整路径、`/Users/`、`/private/tmp/`、`C:\Users\`；
- 本机用户名（`id -un`）：只在路径形式里查，比如 `/<用户名>/`、`\<用户名>\`，免得短名字在二进制里误报；
- `git config user.email`、`git config user.name`（取不到就跳过）；
- 当前环境里代理变量（`ALL_PROXY`、`HTTP_PROXY`、`HTTPS_PROXY` 及小写）的值，有值才查。

所有打进包的文件都要查，二进制也查。报错时说是哪个文件、命中的是哪一类，不要把命中的值打出来。

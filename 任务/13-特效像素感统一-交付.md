# 任务 13 · 特效像素感统一交付

已接入 31 张原生尺寸特效图。爆炸、火花、尘土和冰层在 1920×1080 全屏下每格对应两个屏幕像素，分屏和合作宽屏随各自的井缩放。改动已留在 `t13-fx` 工作区。沙箱拒绝 `git add` 创建 `index.lock`，提交未完成。

## 改动

- `tools/lib/spec.mjs` 和 `art/` 接入 6 张爆炸、12 张火花、12 张尘土和 1 张冰层，清理 8 张旧火花、尘土贴图及其导入配置。
- `scripts/well.gd` 将特效固定为每格 2/3 个设计像素，共用 `res/mat_sharp_unshaded.tres` 的锐利采样。火花和尘土按物件边长选档，帧率、透明度和淡出沿用原设定。96 格冰层换算为 64×64 设计像素，和矿工画布同大、同中心。新旧冰层主体的外框各边偏差最多约 0.33 个设计像素。
- 爆炸最大帧的主体实测为 188×181 格，换算为 125.33×120.67 个设计像素。炸药桶的 `BOOM_R` 换算后直径为 125，横向相差 0.33 个设计像素。手持炸药仍只炸掉正在拉的物件，其事件半径换算后对应 50 个设计像素的直径，火球共用固定尺寸，附加闪光沿用各自的事件半径。
- `scripts/main.gd` 新增本地预览指令，更新了着色器注释、`素材清单.md`、`画面风格说明.md`、`联机设计说明.md` 和 `第三期进度.md`。

## 网页验收指令

在带 `?test=1` 的网页进入挖矿阶段后，可在控制台分开执行以下两条命令。

```js
window.dmQ = [{t: "showFx", k: "spark", s: "m", x: 320, y: 180}]
window.dmQ = [{t: "showIce", i: 1}]
```

`showFx` 的 `k` 支持 `boom`、`spark`、`dust`，火花和尘土的 `s` 填 `s`、`m` 或 `l`，爆炸省略 `s`。`x`、`y` 使用 640×360 设计坐标，分屏可用 `f` 指定井号，默认为 0。`showIce` 的 `i` 是 `window.dmState.players` 中的玩家 ID，预览持续 3 秒。两条指令只在本机显示。

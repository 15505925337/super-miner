## 结论

这次单看超高档一张图就有光照感：长软影、彩色光、灯的明暗都出来了。问题有三个：
- 整面井壁被提亮太多，岩石层、晶洞层原画的暗调没了；
- 熔岩层有一处很淡的波纹；
- 演示局在桌面版会报空指针。

帧率：桌面版补测到了。超高档每帧多 0.7–1.6 毫秒，在这台机器上开销很小。

## 帧率

桌面版：`--disable-vsync --max-fps 0`，演示局，1920×1080，Apple M4 Pro，窗口放在 Mac 自带屏幕上。每组 8 秒，跑两遍。

| 层 | 高档 中位 ms | 超高档 gir=1 | gir=2 | gir=4 |
|---|---|---|---|---|
| 浅土 | 1.19（另一遍是刚启动的 6.94，不算） | 2.04 / 2.78 | 1.85 / 2.43 | 1.85 / 2.38 |
| 岩石 | 1.15 / 1.24 | 1.99 / 2.78 | 1.85 / 2.64 | 1.80 / 2.38 |
| 晶洞 | 1.16 / 1.10 | 2.37 / 2.78 | 2.78 / 2.78 | 2.78 / 2.78 |
| 熔岩 | 1.23 / 1.28 | 2.78 / 2.78 | 2.49 / 2.78 | 2.38 / 2.78 |

- 换成帧率：高档约 770–830 帧，超高档约 330–550 帧，大约是高档的一半。
- 每帧多 0.7–1.6 毫秒。60 帧的预算是 16.7 毫秒，在这台机器上很宽裕。
- 第一遍前半段明显快，后面稳定在 2.4–2.8 毫秒，多半是机器发热或电源状态变化。`gir` 1/2/4 差别在波动范围内。
- 中位数常落在 2.78 毫秒，可能是计时精度的台阶，细节不追。
- 办公电脑和手机：未验证。

## 给用户挑的

1. 整体提亮要不要收：现在岩石层、晶洞层原画的暗调被冲淡了。可以压低反光（`gib`），让灯只照亮附近，远处保持原画的暗。
2. 黑灯要不要用 `gid=1`。
3. 定了以后再修波纹和演示局的空指针。

# 任务 03 · 画面亮度和钩子交付

四层对局以原画为主。浅土、岩石沿用原色，晶洞、熔岩在引擎内提亮。矿灯的微光画在矿工和矿物后面，钩爪常态去掉光晕，黑灯期间在爪口附近开启一盏小范围点光。沿用一级钩爪素材、尺寸和判定半径。

## 参数变化

四层参数按浅土、岩石、晶洞、熔岩排序。绳宽和光柱尺寸使用 640×360 的设计像素。

| 参数 | 旧值 → 新值 |
|---|---|
| 常态环境光 RGB | `(0.50, 0.47, 0.50)` / `(0.33, 0.38, 0.56)` / `(0.34, 0.34, 0.60)` / `(0.40, 0.32, 0.36)` → 四层均为 `(1, 1, 1)` |
| 井底亮度、暗角、全屏调色 | `deep` 为 `0.62 / 0.62 / 0.62 / 0.80`，暗角 `0.62`，全屏调色 `0.60` → 井底亮度倍率 `1.0`，去掉暗角、全屏调色和低档整屏乘光 |
| 底图调色 | 井壁饱和度 `1.12` → 井壁、远景、支架共用参数。伽马 / 对比度 / 饱和度为浅土、岩石 `1 / 1 / 1`，晶洞 `1.18 / 1.02 / 1.04`，熔岩 `1.49 / 1.02 / 1.06` |
| 程序井壁 | 质地 `0.42 / 0.42 / 0.40 / 0.45`，凹凸 `1.0 / 1.1 / 1.2 / 1.2`，发光 `0 / 0.70 / 0.90 / 1.0` → 停用质地和凹凸，仅熔岩保留 `relief_3_e`，发光强度 `0.32` |
| 矿灯和光柱 | 静态点光强度 `0.55–1.50` → 停用。光晕缩放 `0.60 → 0.28`、透明度 `0.38 → 0.18`。光柱强度 `0.26 → 0.045`、画布 `340×340 → 140×140`。晶洞横梁留三圈光晕 |
| 泛光 | `0.24 / 0.28 / 0.36 / 0.44` → `0.06 / 0.06 / 0.04 / 0.06`，阈值 `0.84 → 0.90`，软过渡参数 `0.15 → 0.08` |
| 矿物发光 | 常态自发光倍率 `0.30 / 0.45 / 0.55 / 0.80` → `0.12`。晶石、红宝石点光 `0.70 ± 0.12 → 0.14 ± 0.024`，沿用宝石和金块的闪光动画 |
| 黑灯 | 环境光从各层底色降到约一成并另压井壁 → 统一淡到 `(0.06, 0.06, 0.09)`，随事件恢复到白色。沿用值钱矿物的黑灯自发光上限，石头和炸药桶靠近照明才显出 |
| 钩灯和头灯 | 常态钩灯 `0.80`、头灯 `0.30` → 两盏灯常态关闭。黑灯最强时钩灯 `1.90 → 0.80`、头灯 `0.80 → 0.70`。钩灯径向贴图缩放 `2.25 → 0.32`，名义半径约 41 设计像素 |
| 钩绳 | 绳芯 `1.0 → 1.1`，含描边 `2.2 → 1.4`。绳芯 `#E3BD85 → #CFA46D`，描边 `#4A2914 → #7C4627` |

绳芯和描边从 `raw/miner_1.png` 绳卷的 `(255, 423)` 和 `(248, 406)` 取色，四名矿工共用这套绳卷颜色。绞盘到转轴、转轴到爪口绳环用同一条描边线和同一条绳芯线，圆角接合。1920×1080 全屏下绳芯约 3.3 像素，含描边约 4.2 像素。冰冻和大力沿用蓝白和橙色绳芯，两种状态都带深棕描边。

## 熔岩裂缝对照

熔岩原画缺少岩浆，默认保留弱裂缝。开光影时轻微脉动，关光影时静态，黑灯时淡出。Claude 可用 `?tier=3&lava_cracks=1` 和 `?tier=3&lava_cracks=0` 在相同位置分别截图，供用户决定。**两张对照截图未验证，尚无截图文件。**

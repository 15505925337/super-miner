# 任务 03 · 返工 1 交付

## 绳子

- `scenes/hook.tscn` 将绳芯从 `#CFA46D` 改为米白色 `#FFDEA8`，取自 `raw/miner_1.png` 绳卷亮面 `(252, 406)`，另外三名矿工同点取色一致。描边用绳卷暗面的深棕色 `#7C4627`。设计宽度为绳芯 `1.0`、含描边 `1.67` 像素，1920×1080 全屏下约为 **3 像素绳芯，两侧各 1 像素，总宽 5 像素**。
- `shaders/rope.gdshader` 按 `Line2D` 平铺坐标绘制淡棕斜纹，1920×1080 全屏下约每 5 像素一纹，缩小时淡出。绞盘到转轴和转轴到绳环共用一条绳芯线与一条描边线。冰冻的蓝白和大力的橙色都保留深棕描边和斜纹。[Godot 线段平铺坐标实现](https://github.com/godotengine/godot/blob/ed1daf0bf/scene/2d/line_builder.cpp)

## 熔岩层

| 参数 | 返工前 → 返工后 |
|---|---|
| 伽马 | `1.49 → 1.34` |
| 对比度 | `1.02 → 1.12` |
| 饱和度 | `1.06 → 1.40` |
| 调色后的 RGB 通道倍率 | `(1, 1, 1) → (1.08, 1.05, 0.60)` |
| 岩浆裂缝强度 | `0.32 → 0.60`，保留脉动，裂缝绘制在矿物后方 |

`scripts/well.gd`、`shaders/bg.gdshader` 和 `scenes/well.tscn` 将熔岩岩壁调向暗红和橙红。金块沿用原色，石头保留浅色轮廓，炸药桶在熔岩层加了透明度 `0.28` 的暖色描边。按井壁原图像素和调色公式估算，亮度中位数由 `0.261` 降至 `0.198`，平均色由 `#523D49` 转为 `#4C2C23`。`画面风格说明.md`、`素材清单.md` 和 `第三期进度.md` 已同步更新。

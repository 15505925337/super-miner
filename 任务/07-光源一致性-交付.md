# 任务 07 · 光源一致性交付

四层各用一组主光参数。物件与矿工木台的接触影朝右下，金块沿该层光照方向扫光，十字闪光和描边出现在受光侧。晶洞高光带蓝，熔岩物件下沿带淡红反光。常态环境光为中性白。

## 四层光源

`light_dir` 是光照过去的单位向量，右、下为正。角度按竖直朝下向右偏转计算。灯位是 640×360 设计坐标，依据支架原画里量得的亮区或灯芯定位。

| 层 | `light_dir` | `light_col`（RGB） | 原画依据与灯位 |
|---|---|---|---|
| 浅土 | `(0.707107, 0.707107)`，45° | `(1.00, 0.94, 0.82)` 暖白 | 左上树冠下的斜阳，`(24, 15)` |
| 岩石 | `(0.28, 0.96)`，16.3° | `(1.00, 0.78, 0.52)` 暖橙 | 木支架矿灯，朝下为主，`(81, 51)`、`(403, 51)` |
| 晶洞 | `(0.20, 0.979796)`，11.5° | `(0.64, 0.83, 1.00)` 冷蓝白 | 横梁蓝灯，接近正下，`(135, 20)`、`(322, 20)`、`(520, 20)` |
| 熔岩 | `(0.60, 0.80)`，36.9° | `(1.00, 0.74, 0.47)` 暖橙 | 左侧井架挂灯 `(151, 37)`。下方岩浆裂缝提供反光，`under_col = (1.00, 0.32, 0.20, 0.22)`（RGBA） |

## 参数变化

尺寸以设计像素计，`r` 是换算成设计像素的物件碰撞半径。

| 效果 | 旧值 → 新值 |
|---|---|
| 物件接触影 | 固定偏移 `(0.5, 1.5)`，直径 `2.6r + 10` → 沿 `light_dir` 偏移 `clamp(0.25r, 1.4, 3.2)`，椭圆宽 `2.5r + 4`、高 `2.2r + 3`。透明度倍率 `0.85 → 0.64`，中心不透明度约 `0.64 → 0.48` |
| 矿工接触影 | 无 → 以木台底边中心为锚点，相对矿工贴图中心 `(-11, 31.8)`，再沿 `light_dir` 偏移 `1.35`。椭圆 `42 × 3.5`，透明度倍率 `0.58`，中心不透明度约 `0.44` |
| 金块扫光 | 固定向右下 45°、色值 `(1.00, 0.82, 0.48)` → 随层 `light_dir` 和 `light_col`，抵消贴图旋转。周期 3.1–5.3 秒，每次 0.40 秒，常态和黑灯强度仍为 0.24 和 0.46 |
| 十字闪光 | 固定偏移 `(-0.30r, -0.35r)`、色值 `(1.00, 0.94, 0.78)` → 从受光侧沿主光方向向中心找首个不透明度大于 0.5 的像素，颜色取 `light_col`。甲虫换帧或翻面时重算，闪光跟随它的起伏 |
| 描边与反光 | 个别物件的整圈描边 → 受光侧的 0.9 像素细边，统一取本层 `light_col`，默认强度 0.20，原有分层物件强度 0.28–0.80 沿用。熔岩层新增 0.9 像素下沿反光，透明度上限 0.22 |
| 灯光晕和光柱 | 独立灯色及固定方向 → 取本层 `light_col`，光柱跟随 `light_dir`。灯位、光晕透明度 0.18、光柱强度 0.045 沿用。晶洞只留三处灯芯光晕 |

黑灯时接触影、描边和岩浆反光随事件淡出，恢复时同步淡入。值钱物件按任务 05 保留自发光，开光影时金块扫光加强。低画质或关光影时省略接触影、描边、扫光、光晕和闪光，黑灯事件的基础自发光仍生效。

## 文件

- `scripts/well.gd` 配置四层方向、色值及灯位，绘制台沿接触影并同步画质和黑灯状态。`scripts/item.gd` 管理物件短影和受光侧闪光定位。

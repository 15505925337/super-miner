## 背景

用户同意了三条建议，原话："改吧"。这是第一条：超高档合进 main，电脑默认用它。

合并后文字上没有冲突，只有文档有，已经解决。真正的冲突在物件材质上：
- `scripts/gi.gd`：超高档时 `item.sprite.material = _receive_mat`（`gi_receive.gdshader`），关 GI 时设成 `null`。
- `scripts/item.gd`（任务 09）：`set_look()` 里 `sprite.material = _rim_mat if detail and dark < 1.0 else null`（`sprite.gdshader`，受光边和岩浆下沿反光）。
- 两边互相覆盖。超高档下受光边会丢；关 GI 时物件变成没有材质，受光边也丢。

## 要做的

### 1. 物件只用一个着色器

- 把 `gi_receive.gdshader` 的 GI 受光并进 `sprite.gdshader`（或者新建一个物件着色器，替代两者）。
- GI 受光按参数开关：超高档开 GI 时才生效，其他档和 `gi=0` 时不生效。
- 每个物件只有一个材质，由 `item.gd` 持有。`gi.gd` 不再替换物件材质，只设置参数：比如 GI 贴图、井的原点和缩放、开关。
- 各档的效果都不能丢：

| 档位 | 受光边 | 熔岩层下沿反光 | GI 受光 |
|---|---|---|---|
| 高、中 | 有 | 有 | 无 |
| 超高 | 有 | 有 | 有 |
| 低、关光影 | 无（照 09 现在的行为） | 无 | 无 |

- 黑灯时的行为照 08d 和 09 现在的样子。

### 2. 默认画质分设备

- 电脑默认超高，包括网页版在桌面浏览器里打开，以及桌面版。
- 手机默认高档。
- 网页版判断手机：用 Godot 的 `web_android` / `web_ios` 特性，或者用 JS 看 userAgent、触屏点数，你选，交付时说明用的哪种、为什么。注意 iPad 新版 Safari 的 userAgent 会伪装成 Mac。
- 网址加 `q=` 仍然能强制指定档位；调试键 `[`、`]` 照常能用。
- `main.gd` 开头启动参数的注释跟着改。

### 3. 调试参数

`gi`、`gib`、`gis`、`gir`、`gid`、`demo`、`dark` 都留着。默认值就是 08d 定下的效果：黑灯默认照亮，即 `gid=1`。

### 4. 不动的

服务端、玩法、数值、图都不改。08d 和 09 的画面效果不能变：
- 超高档 = 08d 的画面再加上 09 的受光边；
- 高中低档和现在的 main 一样。

### 5. 文档

- `画面风格说明.md`：写明默认画质的规则；
- `第三期进度.md`：记一笔。

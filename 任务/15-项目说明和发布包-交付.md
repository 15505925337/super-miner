# 任务 15 交付说明

`t15-readme` 已完成仓库首页、三平台启动脚本和打包脚本。**正式发布包待确认**。Godot 自带的 `index.wasm` 含上游贡献者的 GitHub 署名，以及第三方许可证中的邮件列表地址。打包脚本按隐私要求拦截了这个文件，`dist/super-miner-0.3.0.zip` 尚未生成。

## 文件

- `README.md` 介绍玩法、角色、键位、安装、同 WiFi 联机、画质、开发流程和许可，配上提供的四张截图。`docs/.gdignore` 让这些截图只用于仓库说明，避免它们被收进游戏资源包。
- `start.command`、`start.sh`、`start.bat` 是 macOS、Linux 和 Windows 的入口。三者共用 Node 启动逻辑，检查版本和端口，网页能访问后打开浏览器，退出时停止服务。支持 `HOST` 和 `PORT`，玩家解压后只需安装 Node.js 24 或更新版本。
- `怎么运行.txt` 提供随包的简明说明，使用 UTF-8 BOM 和 CRLF。`start.bat` 使用 UTF-8 和 CRLF。
- `tools/package.sh` 先运行 `./export.sh --only`，检查导出文件确实来自本次构建，再用 Python 3 标准库打包并打印字节大小和文件数。`.gitignore` 按本任务要求加入 `dist/`。

## 验证结果

- `./check.sh` 通过。临时复用了本机已有的 TypeScript 开发依赖。
- `./test.sh` 共 123 项，121 项通过，2 项失败。两项分别测试联机重连、HTTP 静态文件，沙箱均拒绝在 `127.0.0.1` 上监听，报 `EPERM`。复跑时给 Node 加了 `--test-force-exit`，以便在监听失败后得到完整计数。
- `tools/package.sh` 通过 Godot 4.7.2 无头导出生成了 9 个本次构建的文件。Godot 报告无法在沙箱内保存编辑器设置。打包在引擎隐私检查处停止。用替身引擎验证了 ZIP 的 22 个文件、解压目录、可执行权限、中文文件名和文本编码，也验证了旧导出和含隐私信息的输入会被拦截。
- `sh -n` 和 `bash -n` 通过。用带空格和中文的路径实测了两个 Unix 入口缺少 Node、Node 版本过低时会等待回车。用替身模拟验证了三平台的端口占用、就绪后打开浏览器和退出清理。README 的四张图片和相对链接均在本地核对通过。

### `start.bat` 逐行说明

| 行 | 作用 |
| --- | --- |
| 1 | 关闭命令回显。 |
| 2 | 限定变量作用域，关闭延迟展开以保留路径中的 `!`。 |
| 3 | 切到 UTF-8 代码页。 |
| 4 | 用带引号的 `%~dp0` 切到脚本目录，失败时退出。 |
| 5 | 备注局域网启动的设置方式。 |
| 6 | 用 `where /q` 查找 `node`。 |
| 7 | 找不到 Node 时跳转到安装提示。 |
| 8 | 检查 Node 的主版本是否至少为 24。 |
| 9 | 版本检查失败时跳转到安装提示。 |
| 10 | 在前台调用共享启动器 `node server/launch.mjs`。 |
| 11 | 保存启动器退出码。 |
| 12 | 恢复原目录。 |
| 13 | 返回启动器的退出码。 |
| 14 | 空行。 |
| 15 | 安装提示的跳转标签。 |
| 16 | 显示中文安装提示。 |
| 17 | 等用户按回车。 |
| 18 | 恢复原目录。 |
| 19 | 返回失败状态。 |

# 任务 08c · 超高档收亮度、缩影子交付

超高档改为局部照亮。井壁远离光源时保留原画底色，软影随距离更快淡出。默认保留黑灯彩光，`gid=0` 可关闭。按着色器公式估算，四层井内平均亮度比高档增加 **5.44、6.98、6.39、7.40**，均低于 +8。实测由 Claude 验收。

## 参数与修复

| 参数 | 08b → 08c |
|---|---|
| 默认反光强度 `gib` | 1.35 → 1.10 |
| 井壁反光曝光系数 | 0.57 → 常态 0.30，完全黑灯 0.70。移除整井环境暗化，只有局部彩光参与混合 |
| 径向衰减 | `1/(1+(d/s)²)` → `1/(1+(d/s)²)²`，覆盖边缘仍平滑淡出 |
| 场景灯衰减尺度、覆盖半径 | 154、1040 → 72、224 |
| 岩浆衰减尺度、覆盖范围 | 88、400 → 34、172 |
| 头灯衰减尺度、覆盖半径 | 42、145 → 37、116 |
| 发光物件覆盖半径 | 四档金块 90/115/145/175 → 72/92/116/140。钻石、红宝石、晶甲虫、钥匙 125/120/120/95 → 100/96/96/76 |
| 软影衰减 | 从按距离渐近补光，改为在 18–178 个设计像素内平滑淡出。98 像素处剩一半遮挡权重 |
| 默认黑灯彩光 `gid` | 0 → 1，保留值钱物件 65% 的发光强度 |

距离均用 640×360 的设计像素。黑灯时井壁可接收彩光，物件受光增益随黑灯归零。石头和炸药桶仍按原有环境光绘制，值钱物件保有原来的贴图自发光。

熔岩层弧形波纹推测来自最近邻距离采样和跳步命中位置的变化。距离场改用双线性采样，命中位置按前后覆盖率插值，步长上限设为 8 像素。空间滤波由五点改为 3×3 九点，使用同一帧的数据。影长是否接近 08b 的一半、放大 4 倍后的波纹是否消失，留给截图验收。

演示局停用界面输入处理，`_input` 先检查演示模式与事件类型才查联机状态。审查了 `ui.gd` 的演示局调用路径，顶部栏跳过玩家名称和颜色查询，房间、商店与暂停界面也不在演示局创建。

## 亮度估算

取演示局固定灯位和物件坐标，以默认 `gir=2` 在 320×180 网格计算各光源的方向、覆盖范围与衰减。令光线可见度为 1，叠加发光值 `L` 后做九点滤波。正常光照下用 `255 × (1-exp(-0.33×L))` 计算井壁增亮，忽略原画混合时从增量里扣掉的部分。按 `0.299R+0.587G+0.114B` 对屏幕 y=260–1060 对应区域取均值。

物件增量按中心受光和整张贴图矩形面积保守计入，对任一原色通道 `C`，像素增益利用 `C×(1-max(R,G,B)) ≤ 0.25` 估算。泛光以 08b 对照图左侧高档像素近似阈值输入，代入现有阈值、各级增益和每层泛光系数，将新增泛光计入井内。该估算省略光线遮挡和前景遮盖，泛光使用的是已有截图近似值。

| 层 | 08b 实测增量 | 08c 井壁估算 | 物件及泛光余量 | 08c 增量估算 |
|---|---:|---:|---:|---:|
| 浅土 | +12 | +4.13 | +1.30 | **+5.44** |
| 岩石 | +38 | +5.74 | +1.24 | **+6.98** |
| 晶洞 | +45 | +5.27 | +1.12 | **+6.39** |
| 熔岩 | +31 | +6.19 | +1.21 | **+7.40** |

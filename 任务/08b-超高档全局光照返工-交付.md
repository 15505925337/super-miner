# 任务 08b · 超高档全局光照返工交付

超高档已改用 **JFA 距离场和二维光线步进**。场景灯的光线可穿过整口井，路径上的物件、矿工、木台、绞车、钩子和绳子都参与遮挡。08a 的 22 像素短射线和短软影核已移除。默认画质仍为高档，分屏及 `gi=0` 使用高档渲染路径。

## 光照做法

每个接收像素向覆盖它的每个发光源投 **5 条射线**，每条最多 **64 步**。射线按到最近轮廓的距离改变步长。场景灯覆盖整井，金块、钻石、红宝石、晶甲虫、钥匙、岩浆和头灯按各自范围与距离衰减发光。灯面的五个固定采样位置与沿途轮廓距离共同生成软影，遮挡离接收点越远，环境补光越多。背景保留原画底光，物件按中心受光整件调色，以原图的亮度余量压住高光。旧版反光和阴影的固定上限已移除。

| 每帧步骤 | Pass 数 | 分辨率 |
|---|---:|---|
| 遮挡蒙版、轮廓种子 | 2 | 各 640×360 |
| JFA 跳跃泛洪 | 11 | 各 640×360，步长从 512 减半到 1，最后再以 1 细化一次 |
| 轮廓距离及内外状态 | 1 | 640×360 |
| 射线照明、空间滤波 | 2 | 各 640×360 ÷ `gir` |
| 合成和物件受光 | 在原主井内绘制 | 主井原分辨率 |

共 16 个离屏 pass。遮挡及距离场保留设计分辨率来覆盖细绳。空间滤波使用当前帧的中心和四邻点。GI 无时间累积，摆钩不会留下上一帧的影子。

## 参数和演示局

| 参数 | 默认值 | 用法 |
|---|---|---|
| `q` / `gi` | `high` / `1` | `q=ultra` 启用超高档，`gi=0` 在该档关闭 GI |
| `gib` / `gis` | `1.35` / `1.45` | 调彩光和遮挡反差，均为 0–2 |
| `gir` | `2` | `1`、`2`、`4` 的射线照明分辨率依次为 640×360、320×180、160×90 |
| `gid` | `0` | 默认黑灯时 GI 归零。`1` 保留金块、钻石、红宝石、晶甲虫和钥匙 65% 的发光强度 |
| `demo` / `dark` | `0` / `0` | `demo=1` 进入演示局，`tier=0..3` 选层，`dark=1` 从首帧保持完全黑灯 |

黑灯时场景灯、岩浆和头灯归零，物件原有的黑灯自发光继续生效。演示局在四层摆同样的 12 件物品和一名摆钩的矿工，只显示顶部信息，无对局 WebSocket。

- 网页可用 `?demo=1&tier=3&q=ultra`。追加 `&dark=1&gid=1` 看黑灯彩光，对比时改成 `gid=0`。可照常追加 `&bench=10` 或 `&shot=08b-lava`，通过现有 HTTP 接口记录结果。
- 桌面版可在 Godot 参数分隔符后用 `-- --demo=1 --tier=3 --q=ultra --gir=2 --bench=10`。截图使用 `--shot=08b-lava`。画质或分辨率对比只需换 `q` 或 `gir`。

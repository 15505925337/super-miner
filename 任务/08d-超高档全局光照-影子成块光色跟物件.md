# 任务 08d：影子成块、只跟主光走，光色跟物件，天空不吃 GI

分支：`t8a-gi`（接着 08c 返工 1 做，不合 main）。先读 `任务/08c-超高档全局光照-收亮度缩影子-验收.md`，开头有更正。

## 背景

设计会话复核 08c，结论是不通过。看的是浅土层右半边，放大 2 倍：`shots/08c-四层-左高档右超高档.png` 的 x 1300–1900、y 150–550，对应超高档原图的 x 664–1864、y 300–1080。

问题有三个，都违反最初定的验收标准："影子方向和本层主光一致"，以及 07a 定下的"不准出条纹"。另外加上 Claude 发现的天空问题。

Claude 看代码找到的原因：

1. **扇形条纹**：
   - `gi_resolve.gdshader` 的 `wall_shadow()` 只打 5 条方向分开的射线（`spread = (i−2)×0.22`），每条各拖出一道暗条；
   - `gi_light.gdshader` 每个光源的 5 条射线也是一样的问题。
2. **多方向影子**：每个发光物件（金块、宝石、甲虫、钥匙）也在 `gi_light` 里算遮挡，所以别的物件在它周围各投一道影子。
3. **光色不对**：
   - `gi_background.gdshader` 的 `daylight_color()` 主要按收到光的亮度去乘原画（`exposure`）；
   - 光本身的颜色只按 `0.20 × (lighting.rgb − received)` 带进去；
   - 所以蓝光照在橙色土上，只是把橙色调亮。
4. **天空**：浅土层矿工的头灯把身后的天空照亮一团，绞车右边的天空上还有一条暗影。

## 要做的

### 1. 每个物件只有一块连续的软影

- 看不出一道一道的条纹。
- 做法你选：
  - 加射线；
  - 每个像素的射线方向加抖动（比如按像素位置的蓝噪声或交错网格），再做空间模糊；
  - 对 GI 结果降噪，比如按距离场或遮挡蒙版引导的双边模糊。
- 交付时写清：射线数、抖动方式、模糊半径。
- 不能有时间累积造成的拖影。

### 2. 主影子只跟本层主光走

- 浅土层是左上的斜阳，影子统一往右下。
- 岩石、晶洞、熔岩层跟各自的灯。
- 发光物件（金块、宝石、甲虫、钥匙）和头灯**只往周围投一圈彩色光，不再给别的物件投影**。就算保留投影，也要淡到看不出方向冲突。

### 3. 光色跟物件走，四层都一样

| 物件 | 光色 |
|---|---|
| 钻石 | 蓝 |
| 红宝石 | 粉红 |
| 金块、钥匙 | 暖金 |
| 晶甲虫 | 紫 |

- 光色要能把墙面染上它的颜色，不能只是把原画调亮。比如：彩色光按色相加一层，或者乘的时候用光的颜色，不用光的亮度。
- 加的量要控制住，不能把井壁整体提亮（见第 5 条）。
- 晶洞层、熔岩层也要检查。

### 4. 天空

二选一，说明理由：
- 地面以上（天空、栅栏、草）不吃 GI；
- 矿工头灯在浅土层不当光源。

### 5. 保持 08c 返工 1 的样子

- 井内平均亮度比高档最多高 8；
- 灯下要亮，远处和影子要压暗；
- 金块不发白，钩子清楚；
- 黑灯默认 `gid=1`；
- 高、中、低三档不变。

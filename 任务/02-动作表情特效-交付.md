## 矿工帧时序

| 状态 | 帧与时长 |
|---|---|
| 摆钩 | `idle` 和 `idle2` 各 1 秒，四个座位依次错开 0.5 秒 |
| 出钩 | 固定 `idle`，保留出钩时端稳绞盘的姿势 |
| 空钩收回 | `crank1..4` 循环，每帧约 83 毫秒 |
| 拉轻货或用大力饮料 | `crank1..4` 循环。收绳速度为 `v` 时每秒 `min(18, 3.5 + v / 95)` 帧。普通小金块约 137 毫秒一帧 |
| 拉重货 | `pull` 和 `pull2` 交替，每秒 `min(10, 2.8 + v / 90)` 帧。普通巨石约 269 毫秒一帧，巨型金块等人帮拉时约 357 毫秒一帧 |
| 拉上有进账的非石头物件 | `happy → happy2 → happy`，依次 200、260、240 毫秒 |
| 拉上石头 | `sad`，800 毫秒 |
| 钩碰炸药桶 | `hit`，1 秒 |
| 用炸药 | `throw`，400 毫秒 |
| 冻结 | 保持屏幕上最后显示的动作帧，原位叠加 48% 不透明度的冰层，矿工本体保留原色 |

轻重以 `shared/balance.json` 的 `TYPES.w ≥ 5` 为界，重货包括大金块、巨石、巨型金块和宝箱。收绳速度 `v` 用服务端坐标单位每秒表示，从前后快照估算，进入拉货尚无同状态快照时按重量和大力状态估算。优先级依次为冻结、中炸、扔炸药、开心或沮丧、钩子动作、待机。

## 掌柜表情

| `ka` | 触发条件 | 代码 |
|---|---|---|
| `think` | 给出中间还价，且未触发吃惊 | `server/src/shop.ts:153` |
| `surprised` | 出价使耐心下降至少 12 点。让到底价或耐心耗尽后拒绝时，优先播对应表情 | `server/src/shop.ts:143` |
| `sigh` | 还到底价、触发最低价兜底，或按底价成交 | `server/src/shop.ts:64`、`server/src/shop.ts:150` |
| `smug` | 成交价达到「底价 + 标价与底价差的 2/3」，按标价购买也适用 | `server/src/shop.ts:64`、`server/src/shop.ts:71`、`server/src/shop.ts:148` |
| `refuse` | 耐心耗尽、达到还价次数上限、出价超过钱包，或明确拒绝且未保留吃惊表情 | `server/src/shop.ts:120`、`server/src/shop.ts:157` |
| `bye` | 该座位已准备下井，等待期间持续显示 | `server/src/game.ts:375` |
| `happy` | 普通成交，或聊天使耐心上升 | `server/src/shop.ts:64`、`server/src/shop.ts:143` |
| `angry` | 聊天使耐心下降至少 12 点 | `server/src/shop.ts:143` |
| `idle` | 进店招呼和其余普通对白 | `server/src/shop.ts:143` |

高兴、生气双帧每 220 毫秒换一张。普通表情持续 3 秒，送别持续到离店。平静时每 3–5 秒随机眨眼一次，约 150 毫秒。新平静对白按 `kn` 触发张合嘴，每帧 140 毫秒，共 1 秒。同机切座位保留各自计时。

## 特效

| 反馈 | 尺寸和时长 |
|---|---|
| 爆炸 | 6 帧、0.5 秒。最大帧的可见范围对应爆炸直径，炸药桶约 125 井内像素，道具炸药约 50。叠 0.32 秒的减亮闪光，震动沿用原设置 |
| 钩中非石头 / 石头 | 钩尖闪星 4 帧、0.3 秒，尘土 4 帧、0.4 秒。最大帧可见范围取物件碰撞半径的 2.5 倍 |
| 合作开箱 | 矿工头上方弹出 24×24 井内像素画布的开箱图，0.18 秒弹出、停 1 秒、0.24 秒淡出。配一次约 16 像素、0.3 秒的闪星 |

爆炸、闪星和尘土在后半程淡出。反馈图在矿物和钩子上方、界面下方，不受场景灯光影响。低画质和关闭光影时继续播放反馈图，省略附加光团。

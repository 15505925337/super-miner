# 任务 14 交付

已在 `t14-dump` 接入网页 `test=1` 的逐帧存图。沙箱对 Git 元数据目录无写权限，改动保留在当前工作区，分支仍指向 `c07e731`。

## 改动

- `scripts/main.gd` 接收 `frameDump` 指令，在绘制结束后截取根视口，经现有接口保存 PNG，并通过 `window.dmState.dump` 公布进度。单笔上传或连续停绘达到 15 秒时会结算失败。最后一帧截完或停绘超时后恢复实时时钟。
- `scripts/cfg.gd` 和 `scripts/client.gd` 在存图时按每帧 1/60 秒推进矿工动作和钩子、物件的快照插值。停绘期间跳过额外步进，快照不足时位置等在最新可用快照。
- `scripts/item.gd` 和 `scripts/well.gd` 将固定步长接到现有的扫光、闪光、甲虫迈步、呼吸光晕及井内动画。光影和素材文件的差异为零。
- `联机设计说明.md` 记录了指令、文件命名、上传状态和时钟范围。服务端规则、网络事件、引擎托管的特效和使用 `TIME` 的着色器仍按真实时间运行。

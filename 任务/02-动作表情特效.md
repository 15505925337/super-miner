| 掌柜表情 | `keeper_think` `keeper_surprised` `keeper_sigh` `keeper_smug` `keeper_refuse` `keeper_bye` `keeper_neutral_blink` `keeper_neutral_talk` | 新增 8 张。头和身体位置和 `keeper_neutral` 完全一样 |

| 开箱 | `chest_open`（上一步已处理进 `art/`，没用） | 和 `chest` 箱体位置一样，盖子掀开 |

每帧画的是什么（出图时的要求）：

- `idle2`：比待机身体下沉一格，呼吸。
- `crank1..4`：摇绞盘一整圈，手柄在上、前、下、后，绳卷纹路跟着转。
- `pull` / `pull2`：吃力拉，第二帧更往后仰、脚蹬地、飞汗。
- `happy` / `happy2`：高兴，第二帧举拳跳起来一点。
- `sad`：拉上来一块石头，垂肩叹气。
- `hit`：被炸，满脸黑灰、头发炸开、眼冒金星。
- `throw`：扔炸药，一只手举过头顶往下扔。
- 掌柜：`think` 客人出价他在掂量；`surprised` 砍得太狠；`sigh` 不情愿地让步；`smug` 这笔他赚了；`refuse` 不卖；`bye` 送客；`happy_move` `angry_move` 是高兴、生气的第二帧（上一步已换成新图，没用上）。
- `boom`：白闪 → 火球 → 最大带碎木 → 暗红冒烟 → 烟散 → 淡烟。`spark`：金色十字星由小变大再变小。`dust`：灰褐土烟冒出、散开、变淡。

### 2. 矿工动作（客户端显示）

现在 `client.gd` 只算出 `idle` `pull` `happy` 三种，`well.gd` 换图。改成下面的规则，帧间隔你定（交付说明里写），**拉东西时摇绞盘的快慢要跟着拉速走**（拉速快摇得快）。

| 状态 | 播什么 |
|---|---|
| 钩子在晃（`st`=0），没别的事 | `idle` 和 `idle2` 慢慢交替，像呼吸。四个人错开节拍，不要同步 |
| 出钩中（`st`=1） | 停在 `idle`（或你觉得更合适的一帧，说明理由） |
| 空钩收回（`st`=3） | `crank1..4` 循环，快 |
| 拉东西（`st`=2 或 `st`=4），东西轻 | `crank1..4` 循环，速度跟拉速 |
| 拉东西，东西重 | `pull` / `pull2` 交替。轻重的分界用 `shared/balance.json` 里 `TYPES` 的 `w`，阈值你定（建议 w ≥ 5，即大金块、大石头、巨型金块、宝箱算重），交付时说明。用大力饮料时（`sg`=1）按轻的播 |
| 拉上来值钱的东西（`get` 事件 v>0，且不是石头） | `happy` → `happy2` → `happy`，约 0.7 秒（现在的 `_joy` 那套） |
| 拉上来石头（`get` 事件，`k` 是 `rs` 或 `rl`） | `sad`，约 0.8 秒 |
| 自己的钩子碰炸了炸药桶 | `hit`，约 1 秒 |
| 用炸药炸掉正在拉的东西 | `throw`，约 0.4 秒 |
| 被冰冻（`fz`=1） | 停在当前帧，叠上 `ice`（不透明度你调，人要看得出是谁），去掉现在的整体变蓝（或保留很淡的一点，说明理由） |

优先级：冰冻 > hit > throw > happy / sad > 拉 / 摇 > 待机。

**服务端要补一点信息**（只为显示，不改规则）：现在 `boom` 事件里没有是谁。钩子碰到炸药桶（`game.ts` 里 `explode` 那处）和用炸药（`useTool` 的 `d`）发的 `boom` 事件，加上触发者 id（字段名你定，比如 `p`）；连环炸的后续爆炸不加。在 `server/test/` 里补测试：两种情况 `boom` 事件带对了人，连环炸的不带。客户端靠这个播 `hit` 和 `throw`。

头灯：上一步每个矿工的头灯按 `idle` `pull` `happy` 三个姿势对过位置。新帧也要对，量出来写进 `HEAD_LAMPS`（或者你证明某些帧可以共用某个姿势的位置）。绳卷出绳点上一步量出来所有帧都一样，新帧也核对一下，如果摇绞盘时绳卷位置不变就不用动。

### 3. 掌柜表情（服务端定情绪，客户端换图）

服务端的 `ka` 现在只有 `idle` `happy` `angry`。按下面扩充（只是显示用的标签，**价格、心情、成交规则一律不改**），在 `server/test/` 里补测试，覆盖每一种：

| `ka` | 什么时候 |
|---|---|
| `think` | 客人出价，他还了个中间价（`counter`） |
| `surprised` | 客人出价低得离谱、心情掉得多（现在 `dm <= -12` 算 `angry` 的那种，出价时改成 `surprised`；说话骂人还是 `angry`） |
| `sigh` | 让步到底价（"这个数真不行，最低 ¥…"，或者按底价成交） |
| `smug` | 成交价高于底价较多（比如按标价或接近标价成交，阈值你定），原来是 `happy` |
| `refuse` | 不卖：心情到 0 不讲了、这件磨太多次、钱不够还讲价 |
| `bye` | 这个玩家点了下井（准备好了） |
| `happy` `angry` `idle` | 其余情况照旧 |

客户端：

- 每种 `ka` 换对应的图。`happy`、`angry` 两帧交替（`happy`/`happy_move`、`angry`/`angry_move`），节奏你定。
- `idle`（显示 `keeper_neutral`）时每 3 到 5 秒随机眨一次眼（`keeper_neutral_blink`，约 0.15 秒）。
- 掌柜说新的一句话时（`kn` 变了），如果当前是 `neutral`，嘴巴张合（`neutral` / `neutral_talk` 交替）约 1 秒；不是 `neutral` 时不张嘴。
- 一个表情显示一段时间（比如 3 秒）后回到 `neutral`，`bye` 除外（一直挥手到离开商店）。时长你定，写进交付说明。

### 4. 特效

现在的爆炸、钩中都是一团光（`well.gd` 的 `fx_boom`、`fx_hit`）。

- **爆炸**（`boom` 事件）：播 `boom_1..6`，总长约 0.5 秒，大小按爆炸半径（最大那帧的火球大约盖住爆炸半径）。现在的光团和震动保留，作为闪光叠在上面，亮度可以调低。
- **钩到值钱东西**（`grab` 事件，`k` 不是石头）：在钩子的位置播 `spark_1..4`，约 0.3 秒，大小和被钩的东西差不多或略大。
- **钩到石头**（`grab` 事件，`k` 是 `rs` 或 `rl`）：在钩子的位置播 `dust_1..4`，约 0.4 秒。
- **开箱**（合作：`get` 事件 `k` 是 `chest`）：在矿工头上方显示 `chest_open`，弹出来、停约 1 秒、淡出，配一次 `spark`。
- 特效不吃场景灯光（自己就是亮的），画在物件和钩子上面、界面下面。
- **好看不能妨碍瞄准**：特效不能长时间盖住别人的钩子和矿物；画质低档（`Q.LOW`）或关光影（`fx_on` = false）时，特效照样播（这是玩法反馈），但去掉附加的光团。

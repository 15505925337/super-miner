# 动态检查（tools/dyncheck）

完美版标准第 3 条：画面里静止不动的区域，相邻帧亮度变化不超过 2；拉动物件时影子和光晕跟得上。这些脚本由 Claude 验收时用，Codex 不要跑（要起服务端和浏览器）。

## 跑法

```
DM_EVENTS=none DM_ROUND_T=120 ./server.sh 8066        # 关掉随机事件、每关 120 秒
tools/dyncheck/run.sh "http://localhost:8066/?test=1" 1,4,7,10 /tmp/dyn
```

- 无头 Chrome，不弹窗口；画布 1920×1080（`W`、`H` 可改）。
- 单人闯关开自动玩（`window.dmAuto`），商店直接下井；到了指定关卡，在剩余 115–80 秒之间（`TLMAX`、`TLMIN`）各存两段：`idle`（关掉自动玩、钩子空摆）、`haul`（开自动玩、抓到东西往回拉）。每段 `N` 帧（默认 70）。
- 存图用游戏自己的 `frameDump`（`test=1`），存图期间客户端动画按固定 1/60 秒步进，所以相邻两张就是游戏里相邻的两帧；文件名带引擎帧号，脚本会核对是否连续。

## 输出怎么看

- `帧数 … 不连续处 0`：帧号连续，确实是相邻渲染帧。
- `still.mjs`：排除有东西在动的块（任一相邻帧块均值变化 >15 及其周围两圈）后，井内静止块的相邻帧变化。最大值应 ≤2。
- `flip.mjs`：块平均亮度相邻变化 >2 且正负号反转 4 次以上的块（真正的闪烁会一亮一暗来回跳）。列出来的位置要逐个看图对原因（扫光、十字闪光、甲虫迈步、熔岩裂纹都会出现在这里，不算闪烁）。
- `median.mjs`：每块相邻变化的中位数。持续闪烁会抬高中位数；墙面应接近 0。
- `shake.mjs`：相邻帧有没有整屏平移。拉到大钱时会震屏，整屏一晃，那一段墙面的数字会很大，不算闪烁；判断闪烁主要看 `idle` 段。
- `follow.mjs <段目录> <输出png>`：拉回段连续 16 帧拼图，看影子、光晕是否贴着物件走。

## 其他

- `seed.cjs`：`NODE_OPTIONS="--require tools/dyncheck/seed.cjs" ./server.sh 端口` 让服务端用固定随机种子，两个服务端按同样顺序开局，井就一模一样，用于改前改后对比截图（合作局有电脑玩家，每组截图前两个服务都要重启）。
